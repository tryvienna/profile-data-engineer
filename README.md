# 📊 Data Engineer / Data Scientist

> Ask your data anything, in plain English

A Vienna content profile for data engineers and data scientists. Includes quick actions for SQL generation, dbt model creation, pipeline debugging, data profiling, cohort analysis, and query optimization.

## What's included

- **Quick Actions** — Write SQL queries, generate dbt models, debug DAG failures, profile datasets, create cohort analyses, optimize slow queries
- **Skills** — Getting started guide for Vienna profiles
- **Plugins** — Linear for data team task tracking

## Install

Fork this profile in Vienna:

```
vienna://profile/github.com/tryvienna/profile-data-engineer
```

Or go to **Settings → Profiles → Fork** and paste:
```
https://github.com/tryvienna/profile-data-engineer.git
```

## Customize

After forking, this profile lives at `~/.vienna/profiles/data-engineer/`. Edit any file to make it yours — add quick actions, swap plugins, tweak skills.

## Share

Push your customized profile to your own GitHub repo and share the `vienna://profile/...` link. Others can fork your version in one click.
